# surprice-for-you

🌸 **A Little World Made For Her**

A romantic, retro-pixel-art-inspired handheld gaming experience dedicated to my favorite person.

## Features
- 🌟 **Screen 01: Retro Boot Screen** with typewriter loading sequence, pixel stars, and heart indicator
- 🎮 **Screen 02: Handheld Game Console** with animated sky, pixel grass, floating hearts, and cute dialogue system
- 🌺 **Screen 03: Flower Surprise** — carefully crafted pixel bouquet and romantic message directly inside the handheld screen
- 💌 **Screen 04: Love Letter Terminal** — 7 typewriter love notes with retro dialogue box styling
- ♫ **Interactive Music Player** with HTML5 Web Audio API romantic melody

## Tech Stack
- **React + Vite**
- **GSAP** for smooth timeline animations
- **CSS** for pixel-art UI and scanline effects
- **Web Audio API** for synthesized romantic melodies

## Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) to enjoy the experience!
